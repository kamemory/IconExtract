# EXE/DLLあたりからアイコン抽出しとくれ

WindowsのEXE/DLLファイルからアイコンリソースを抽出し、icoファイル、pngファイルとして保存します。
ショートカットファイル(`*.lnk`)もリンク先を参照し、EXE/DLLファイルであれば抽出対象となります。

上手くいかない場合も多分あります。

## インストール

[Release](https://github.com/kamemory/IconExtract/releases)からzipファイルをダウンロードして、適当なフォルダに展開。

.NET9.0のランタイム？が必要？ですけど？

## アンインストール

レジストリとかは(多分)使わないので、そのままインストールしたフォルダごと削除。

## 使い方.A

1. 起動します。
2. 抽出したいEXE/DLLファイルをドラッグ＆ドロップ。
3. `一括抽出`ボタンをシューッ。
4. ツールと同じフォルダ内に`out`フォルダが作成され、さらにEXE/DLLファイル名のフォルダができるので、その中にアイコン画像が出力されてます。

## 使い方.B

1. EXE/DLLファイル等をまとめて`IconExtract.exe`にドラッグ＆ドロップ。
2. ツールが起動し、勝手に変換が始まります。
3. 終わったらツールが勝手に終了します。
4. ツールと同じフォルダ内に`out`フォルダが作成され、さらにEXE/DLLファイル名のフォルダができるので、その中にアイコン画像が出力されてます。

Windowsの`送る`などに登録して使用してもいけると思います。
